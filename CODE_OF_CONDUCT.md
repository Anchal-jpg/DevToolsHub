# 📜 Code of Conduct

## Our Commitment

We want DevToolsHub to be a welcoming and respectful open-source project for everyone.

All contributors are expected to communicate respectfully and help create a positive environment.

## Expected Behavior

* Be respectful and polite.
* Give constructive feedback.
* Welcome beginners and new contributors.
* Focus on improving the project.
* Respect different opinions and approaches.
* Help others when possible.

## Unacceptable Behavior

The following behavior is not acceptable:

* Harassment or discrimination.
* Personal attacks or insults.
* Trolling or intentionally disruptive behavior.
* Sharing private information without permission.
* Any other behavior that makes the community unsafe or unwelcoming.

## Reporting Problems

If you experience or notice unacceptable behavior, please contact the repository maintainer through GitHub.

Reports will be handled as respectfully and confidentially as possible.

## Enforcement

Maintainers may remove comments, close discussions, reject Pull Requests, or take other appropriate actions when this Code of Conduct is violated.

Thank you for helping make DevToolsHub a friendly open-source community.
