# 🤝 Contributing to DevToolsHub

Thank you for your interest in contributing to DevToolsHub!

DevToolsHub is a beginner-friendly open-source project where developers can build useful tools and learn how to contribute through GitHub Issues and Pull Requests.

## 🚀 How to Contribute

### 1. Find an Issue

Check the open GitHub Issues and find an issue you would like to work on.

### 2. Ask to Work on the Issue

Before starting work, comment on the issue.

For example:

> I would like to work on this issue.

Please wait until a maintainer assigns the issue to you before starting.

### 3. Fork the Repository

Fork this repository to your GitHub account.

### 4. Create a Branch

Create a new branch for your work.

Examples:

```text
feature/password-strength-checker
feature/github-readme-generator
fix/json-validation
```

### 5. Make Your Changes

Implement only the feature or fix described in the issue.

Please avoid making unrelated changes.

### 6. Test Your Changes

Before creating a Pull Request:

* Make sure the feature works correctly.
* Test it on different screen sizes.
* Check for JavaScript errors.
* Make sure existing functionality still works.

### 7. Create a Pull Request

Push your branch to your fork and create a Pull Request to the `main` branch of DevToolsHub.

In your Pull Request description, include:

```text
Closes #ISSUE_NUMBER
```

Replace `ISSUE_NUMBER` with the number of the issue you worked on.

## 📌 Contribution Rules

* Do not start working on an issue that is already assigned to someone else.
* Comment on an issue before starting work.
* Keep Pull Requests focused on one issue.
* Do not make unrelated changes.
* Write clean and readable code.
* Test your changes before submitting a Pull Request.
* Do not commit passwords, API keys, tokens or other secrets.
* Be respectful and helpful to other contributors.

## 💡 New Ideas

Have an idea for a useful developer tool?

Open a GitHub Issue and describe:

* What the tool should do
* Why it would be useful
* How you think it could work

We welcome useful and beginner-friendly ideas!

Thank you for contributing to DevToolsHub! 🎉
