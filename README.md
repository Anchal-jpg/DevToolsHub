# 🛠️ DevToolsHub

DevToolsHub is an open-source collection of useful developer tools built with HTML, CSS and JavaScript.

The goal of this project is to create simple, useful and beginner-friendly tools while helping developers learn Git, GitHub, Issues and Pull Requests.

## 🚀 Tools

Tools will be added by contributors.

Some planned tools:

* Password Strength Checker
* GitHub Profile README Generator
* JSON Formatter
* Markdown Previewer
* Color Palette Generator
* Text Case Converter

## 🤝 Contributing

Want to contribute?

1. Check the open GitHub Issues.
2. Comment on an issue you want to work on.
3. Wait until the issue is assigned to you.
4. Fork the repository.
5. Create a new branch.
6. Make your changes.
7. Test your changes.
8. Create a Pull Request.

Please read `CONTRIBUTING.md` before contributing.

## 🌟 Goal

Build a collection of simple, useful and beginner-friendly developer tools while helping contributors learn Git and GitHub.
